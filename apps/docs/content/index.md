---
title: Admin panels for Node.js.
---

Navette is a TypeScript framework for building admin panels, dashboards and back-office tools on Node.js: resources, forms, tables, actions, widgets, notifications, authentication and multi-tenancy, rendered on the server.

```bash
npm create navette@latest my-app
cd my-app && npm run dev
```

Then generate your first screen from a database table with `npx navette make:resource Post --generate`.
